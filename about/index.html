关于我

我是谁

AI Infra 工程师 / 平台工程 / 场景交付。 10 年以上企业基础设施经验，从甲方 IT 管理、公司级平台从 0 到 1 建设，到机场、设计云、超算云的大型客户交付。现在在源策未来从 0 到 1 搭整套基础设施，面向具身智能研发：把通信、算力、模型环境、数据协同与可观测组织成统一平台，用实机基准和恢复验证支撑持续交付。

我信奉的事

  • 架构视野 · 工程纵深 · 独立交付。 方案要能画成架构图，落得要能回滚，结的算要有数字。
  • 量化口径先行。 每个性能数字都带统计口径：同权重、同输入、同依赖的离线 A/B，前后输出对齐的单轮对照——不拿「感觉变快了」交差。
  • 先给结果、证据说话。 每一步可复现，每个结论可回查；API 200 不算业务证据，真流量才算。
  • AI Native 五维基准。 Agent-first OS、数据写入即语义化、事件驱动 Agent Swarm、知识自动回流、自然语言操作面——我按这套框架给自己定位：v2.0 AI-Augmented（监控=眼睛、堡垒机=手、Agent=脑、知识库=记忆），v3.0 在路上。

六大能力面

公司级架构与大型交付

独立承担源策基础设施从 0 到 1：办公、研发、机房与云端，网络、安全、身份、算力、存储、混合云一路贯到 AI 原生运维。此前主导机场 AI 超级大脑、华建设计云的基础设施交付，负责同济超算云全栈运维——兼具架构建设与客户现场交付能力。

异构算力与性能工程

以 PVE 及异构 GPU（L40S / RTX PRO 6000 / DGX Spark）支撑推理，实践 CPU 亲和、NUMA、MIG / vGPU / SR-IOV 调优；掌握 vSphere / vSAN 与存储网络。每一次调优都留可复现基准：

NUMA 拓扑调优：均值 202.24 → 193.08 ms（-4.53%），P95 210.59 → 199.84 ms（-5.10%）（同权重/输入/依赖的离线 A/B）
四路预热 CUDA Graph 回放：各来宾均值 119.8 – 122.9 ms（固定输入模型回放，与 A/B 分开计量）

网络架构与多云互联

M-LAG 双机聚合、100GE 骨干、VLAN 分区与访问边界；AP 射频测量、流媒体参数与组播分发的跨层优化；阿里云 / 火山引擎 IPsec 现网联通，10G 裸光纤云地互联纳入目标架构。WBI 全球演示分发：126 城市测速报告、HTTP/2 + 二级缓存预热、15 项协议检查通过。

数字身份与零信任治理

设计「飞书（组织主数据/UPN）→ 飞连（口令权威/接入认证）→ AD（目录/组策略/资源权限）」的职责链，Entra ID 云身份按规划在下游扩展。身份匹配 100%（85/85），340 项权限一致性核验；人员同步单轮耗时 15.3 → 7.8 分钟（-49.4%）。

平台研发与交付工程

贯通实验环境复制（3 套机器人环境、277 个模型文件约 118.3 GB）、共享模型数据、GPU 许可与 CI 构建；推进 Go 控制面与跨端组件（Swift / C# / C++）研发，目录认证、双向 TLS、策略心跳完成阶段验证，CI 验证轮 4/4 作业通过。

AI Native 与 Agent 协作

结合知识检索（WeKnora）、模型服务（LiteLLM）与受限智能体，实践主控拆解 → 专项执行 → 独立复核 → 知识回流的受控分工；场景隔离、有界重试、实机回读，沉淀可复用工具和规程。
