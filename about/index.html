关于我

技术专长

  • GPU 算力与推理服务：数据中心级 GPU 服务器（vGPU/MIG 切分）与边缘推理设备的选型、部署与调优，模型推理服务的参数调优与多 Agent 接入。
  • 虚拟化与裸金属：Proxmox VE / Hyper-V / VMware 平台的落地实践，覆盖 ZFS、cloud-init、网卡业务平面隔离等基础设施层细节。
  • 身份与目录服务：AD DS 与 Entra ID 的混合域环境搭建、多站点部署与排障。
  • 系统集成：存储、网络（路由交换/防火墙）、终端与国产化平台的整体交付，强调可回滚、可验证的实施方案。
  • Linux 运维：Ubuntu/CentOS 的补丁策略、监控（Zabbix）与自动化运维。

工作经历

从系统集成工程师起步，先后负责企业域环境建设、多数据中心 GPU 算力平台交付与国产化适配，近两年重心转向 AI Infra：裸金属算力、模型推理服务、身份边界与交付物的工程化。习惯用「先给结果、证据说话」的方式做事：每一步可复现，每一个结论可回查。
